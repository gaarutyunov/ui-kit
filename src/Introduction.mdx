# GA UI Kit

A **universal, zero-dependency UI kit** built on native **Web Components**. The
visual language is distilled from two projects — the
[garutyunov.com](https://github.com/gaarutyunov/garutyunov.com) portfolio and the
[stereoscope](https://github.com/gaarutyunov/stereoscope) converter — into a single
Geist-inspired, pure-black design system.

Because every component is a standard custom element (`ga-*`), it runs **anywhere**:
vanilla HTML, React, Astro, Vue, Svelte, SolidJS — no framework adapter required.

> 📱 **On a phone?** This Storybook UI is desktop-oriented. For a mobile-friendly
> tour of every component (no Storybook), open the
> [**standalone showcase**](demo/test.html).

## Quick start

```html
<!-- 1. Theme (optional but recommended) -->
<link rel="stylesheet" href="https://esm.sh/@gaarutyunov/ui-kit/tokens.css" />

<!-- 2. Components (registers every <ga-*> element) -->
<script type="module">
  import "https://esm.sh/@gaarutyunov/ui-kit";
</script>

<ga-button variant="primary">Hello</ga-button>
```

## With a bundler

```bash
npm install @gaarutyunov/ui-kit
```

```js
import "@gaarutyunov/ui-kit";            // register all components
import "@gaarutyunov/ui-kit/tokens.css"; // global theme
```

## Theming

Re-brand the entire kit by overriding a handful of CSS variables — exactly the
`--accent` / `--radius` pattern stereoscope uses:

```css
:root {
  --ga-accent: #ac4bff;   /* purple instead of blue */
  --ga-radius: 10px;
  --ga-font-sans: "Inter", system-ui, sans-serif;
}
```

Switch to the bundled light theme with `<html data-theme="light">`.

## Why Web Components?

| Concern | How the kit handles it |
| --- | --- |
| **Framework portability** | Native custom elements — no React/Vue-specific build |
| **Style isolation** | Shadow DOM; host page styles can't leak in |
| **Theming** | CSS custom properties pierce the shadow boundary |
| **Zero runtime deps** | ~3 KB base class, no Lit/Stencil |
